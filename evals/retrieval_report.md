## How to read this

- **Categories.** `text` = the 50 original W8 questions; `paraphrase` = 50 LLM paraphrases of them (free model, synthetic); `graph` = 50 template questions from `scripts/gen_qa_graph.py` whose right runbook depends on a topology fact (access vs core link, link vs cell, the hub a site homes on).
- **Caveats.** Paraphrases are easy here (every mode scores 1.0). Graph questions are template-made over one synthetic topology (seed 42). The reranker weights were tuned on this same set, so the graph gain is optimistic; the reranker gives no gain on plain-text questions (text hit@1 0.94 hybrid -> 0.90 graph/rerank).
- **Modes.** `rerank` = hybrid + feature reranker without graph context (ablation); `graph` = entity linking + catalogue text-to-Cypher plan + neighbourhood expansion + rerank. Latency is in-process (hash embedder, local graph), excluding HTTP.
- Regenerate: `make rag-bench` (Docker only) or `uv run python -m rag_service.bench --modes vector,hybrid,graph --out evals/retrieval_report.md`.
