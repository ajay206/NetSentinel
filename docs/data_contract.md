# Data contract (W24)

All data is **synthetic**, generated by `libs/netgen` and `services/ml-service/src/ml_service/synth_faults.py` with fixed seeds. No CSG, customer or operator data is allowed in the repo, the images or the CI artifacts.

## Producers and topics

| Topic / store | Producer | Schema | Key fields | Retention |
|---|---|---|---|---|
| `alarms.raw` | netgen-simulator | TMF642-style alarm (`contracts/`) | `id`, `siteId` (`SITE-\d{3}`), `perceivedSeverity`, `alarmRaisedTime` (UTC ISO-8601), `specificProblem` | 7 days |
| `alarms.enriched` | alarm-ingest | raw alarm + `enrichment`, `dedup`, `correlation` | same `id`; `dedup.key` | 7 days |
| `kpis` | netgen-kpis | `{cellId, ts, kpi, value}` | `cellId` (`SITE-…-N…-C…`) | 7 days |
| `incidents` | incident-service | incident cluster | `id` (`INC-[0-9A-F]{10}`), `version` | 7 days |
| TimescaleDB `kpi_samples` | kpi-service | hypertable | `(cell_id, ts, kpi)` | compose volume |

## Model features (fault classifier)

`ml_service.features.FEATURE_NAMES` is the contract. Adding, removing or reordering a feature is a breaking change. When that happens:
1. retrain;
2. refresh the eval gate champion in `evals/gate_thresholds.json`;
3. update the model card `docs/model_card_fault_classifier.md`;
4. re-sign the model.

The PSI drift check (`evals/drift_check.py`) compares these features between training and recent data.

## Rules
- Times are UTC in data; the console shows IST.
- Producers must not add free-text fields that could carry personal data. Operator notes stay inside the incident/ticket services and never go into metrics or traces.
- Schema changes need a contract test update (`make *-contract`) in the same PR.
